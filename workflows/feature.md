# Feature Workflow

Follow this lifecycle:

1. Discovery
2. Project Analysis
3. Stack Detection
4. Understand the requirement
5. Complexity Analysis
6. Architecture Analysis when required
7. Design Pattern Analysis when relevant
8. Present significant decisions to the human
9. Implement
10. Test
11. Typecheck
12. Lint
13. Review
14. Inspect Git diff
15. Generate commit proposal
16. Ask for commit approval
17. Commit when approved
18. Provide Engineering Insights

## Scope

Do not modify unrelated code.

## Architecture

Reuse existing architecture unless a justified architectural change is approved.

## Patterns

Never introduce a design pattern merely because one exists.

## Completion

A feature is not complete merely because the code compiles.

It must be validated according to the project's available quality gates.
